# Advanced Robotics & Control Systems Simulation Projects
This repository contains engineering simulations, control algorithms, and mathematical modeling tools developed for mechatronics and autonomous systems applications. 

## Repository Contents

### 1. Autonomous Navigation & Path Planning
* **Robust_Autonomous_Robot_Navigation_CORRECTED.ipynb**: Implements spatial pathfinding algorithms for optimal robot trajectory planning.
* **Dynamic_Obstacle_Avoidance.ipynb**: Utilizes real-time simulated sensor data arrays to calculate collision-free paths in changing environments.

### 2. Control Theory & Actuator Mechanics
* **DC_Motor_PID_Control_EEE_Project.ipynb**: A Proportional-Integral-Derivative (PID) simulation modeling precision feedback loops for velocity and position tuning.
* **Robotic Actuator Dynamic Torque & Motor Selection Calculator.ipynb**: An analytical engineering script designed to calculate dynamic torque limits, load distributions, and motor profiles for multi-joint robotic assemblies.
